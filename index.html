Política de Privacidade — ProspectPro (modo extensão)

Última atualização: 18 de setembro de 2026.

Esta política descreve como a extensão de navegador ProspectPro — WhatsApp (modo extensão) trata dados ao ser usada sobre o WhatsApp Web.

O que a extensão faz

A extensão é um mini-CRM que funciona como uma camada sobre o WhatsApp Web (web.whatsapp.com), permitindo salvar leads, organizá-los em um funil (colunas do tipo Kanban) e inserir mensagens prontas na caixa de digitação. Não é um produto oficial da Meta/WhatsApp.

Quais dados são lidos

Para funcionar, a extensão lê da própria página do WhatsApp Web, via DOM, no navegador do usuário:

  • Nome e, quando visível, número de telefone do contato da conversa aberta;
  • Foto/avatar do contato (endereço da imagem já exibida pelo WhatsApp Web);
  • Trecho da última mensagem e contagem de não lidas, exibidos na lista de conversas;

Esses dados são usados apenas para exibir e organizar as informações dentro da própria interface da extensão (ex.: card do lead, lista de conversas).

Onde os dados ficam armazenados

Todo o armazenamento é local, usando a API chrome.storage.local do navegador do próprio usuário. A extensão não possui backend, não faz chamadas de rede a servidores próprios ou de terceiros, e não sincroniza dados com nenhum serviço externo.

Compartilhamento de dados

Nenhum dado é vendido, compartilhado ou transferido a terceiros. Nenhum dado sai do dispositivo do usuário.

Uso de código remoto

A extensão não carrega nem executa código remoto. Todos os scripts são empacotados localmente na própria extensão.

Permissões solicitadas

  • storage — para salvar localmente leads, colunas do funil e preferências (como tema).
  • host_permissions para https://web.whatsapp.com/* — para inserir a interface da extensão e ler dados da conversa aberta.

Retenção e exclusão de dados

Os dados permanecem armazenados localmente até que o usuário os apague manualmente pela própria extensão ou desinstale a extensão do navegador, o que remove todos os dados salvos.
